# 中学生人工智能素养测评游戏

**Game-based Assessment Tool for Middle School Students' AI Literacy**

> **项目状态**：研究与开发阶段。当前仓库仅包含项目说明文档，游戏功能尚未实现，技术栈待补充。

## 项目简介

本项目是面向中学生设计与开发的人工智能素养游戏化测评工具，旨在探索游戏化测评在中学生人工智能素养评价中的应用方式。

项目以中学生人工智能素养测评框架为依据，选取「未来校园」作为游戏背景，将人工智能知识、技术应用、问题解决及相关素养要求融入连续的游戏任务之中。通过构建具有情境性、交互性和连续性的游戏任务，引导学生在完成游戏任务的过程中展现自身的人工智能素养水平。

与传统问卷测评方式不同，本项目不仅关注学生的任务完成结果，还注重采集学生在游戏过程中的行为数据，为分析学生的任务完成情况、决策行为及问题解决过程提供依据。

## 研究目标

本项目主要围绕以下目标展开：

1. **测评任务游戏化设计**：将人工智能素养测评内容转化为具有真实情境和交互体验的游戏任务。
2. **多维度素养测评**：依据选定的中学生人工智能素养测评框架，设计覆盖不同测评维度和能力水平的任务。
3. **过程性数据采集**：记录学生在游戏过程中的操作行为、任务选择、决策过程及完成情况，为测评提供多元证据。
4. **测评工具应用与效果检验**：通过实际应用考察游戏化测评工具的使用效果，为工具的优化与完善提供依据。

## 游戏设计

### 游戏情境

游戏以「未来校园」为核心背景，构建人工智能技术广泛应用的校园环境。学生作为游戏参与者，通过完成一系列连续任务，解决未来校园中的不同问题。

### 游戏任务

游戏采用主线任务与子情境相结合的设计方式，设置五个连续的主线任务。每个主线任务包含若干具体游戏情境，并根据测评框架融入相应的测评内容。

不同测评维度及能力水平将在各任务中交叉呈现，以考察学生在不同情境下的人工智能素养表现。

### 测评依据

本项目采用已有的中学生人工智能素养测评框架作为测评依据，不另行构建全新的素养框架。

在能力水平设计方面，参考 UNESCO 学生人工智能能力框架的三个进阶层级，将其作为各测评维度内部能力掌握程度的区分依据。

## 过程性数据采集

过程性数据采集是本项目的重要设计内容。

在学生参与游戏的过程中，系统拟记录以下信息：

- **基本信息**：参与者编号、任务编号等。
- **任务行为数据**：任务开始时间、完成时间及任务完成状态。
- **交互行为数据**：操作记录、选项选择及交互次数。
- **决策行为数据**：学生在不同情境下的选择及决策结果。
- **任务结果数据**：任务得分、完成情况及相关评价信息。

通过对过程性数据与任务结果数据的综合分析，为推断学生人工智能素养表现提供依据。

具体数据字段及采集规则以系统实际开发实现为准。

## 开发计划

项目按照以下阶段逐步推进：

1. **需求分析与框架确定**：明确研究对象、测评目标及测评框架。
2. **游戏化测评工具设计**：完成未来校园情境、主线任务及具体测评任务设计。
3. **游戏原型开发**：实现游戏界面、任务交互及基本测评功能。
4. **过程性数据采集功能开发**：实现游戏行为数据的记录与整理。
5. **工具应用与优化**：开展实际应用，根据应用情况优化游戏功能。
6. **测评效果检验**：分析应用数据，考察游戏化测评工具的实际效果。

## 研究意义

本项目尝试将游戏化设计与人工智能素养测评相结合，探索利用游戏交互过程获取学生能力表现证据的可行路径。

通过将测评任务嵌入连续的游戏情境，并结合过程性行为数据采集，丰富人工智能素养测评的证据来源，为中学生人工智能素养测评工具的设计与应用提供实践参考。
